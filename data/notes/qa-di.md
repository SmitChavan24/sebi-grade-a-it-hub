# Data Interpretation

## Why DI decides the section

DI typically carries the largest block of marks in Quant, and it rewards **calculation discipline** far more than mathematical insight. Most candidates lose marks to arithmetic slips and to attempting the wrong set, not to conceptual gaps.

## Types

**Tables · Bar graphs (simple, stacked, grouped) · Line graphs · Pie charts (degrees: 100% = 360°, so 1% = 3.6°) · Caselets (text-based) · Mixed/combination sets · Missing-data DI · Data sufficiency**

## The method

1. **Spend 30 seconds reading the chart before any question** — axis labels, units (lakhs? crores? percentages?), the time period, and any footnote. Most DI errors come from misreading units.
2. **Scan all questions in the set**, and attempt the direct-read ones first.
3. **Approximate aggressively** where options are far apart; calculate exactly only when they are close.
4. **Leave a set entirely** if it requires heavy computation for every question and other sets are available. Set selection is a skill.

## Approximation techniques

- **Percentage as fractions:** 12.5% = 1/8, 16.67% = 1/6, 33.33% = 1/3, 14.28% = 1/7. Converting before multiplying is much faster.
- **Ratio comparison without dividing:** to compare a/b and c/d, cross-multiply — compare **ad with cb**.
- **Percentage change = (new − old)/old × 100.** The denominator is **always the old value** — the most common DI mistake.
- For "which year had the highest growth", compare **ratios**, not absolute differences.
- Round to two significant figures when options differ by more than 5%.

## Speed arithmetic worth drilling

- **Tables up to 25**, squares to 30, cubes to 15.
- **Multiplication by 5** = ×10/2; **by 25** = ×100/4; **by 11** = shift and add.
- **Percentage of a number:** 10% then scale. 35% of 480 = 48 + 48×2.5 = 48 + 120 = 168.
- Reciprocals: 1/7 = 0.1428, 1/9 = 0.111, 1/11 = 0.0909, 1/13 = 0.0769.

## Common question forms

| Form | Approach |
|---|---|
| Direct read | Locate and answer — do these first |
| Ratio between two categories | Cross-multiply, do not divide |
| Percentage change over years | (New − Old)/Old |
| Average across categories | Sum then divide; watch for weighted cases |
| "Approximately what percentage" | Estimate; options will be far apart |
| Combination with missing data | Solve the missing value first using a total |

## Data sufficiency

Do **not** solve. Determine only whether the information is **enough**.
1. Check statement I alone.
2. Check statement II alone.
3. Only then both together.
Never carry an assumption from statement I while testing statement II — that is the single biggest source of error.

---

## Exam pointers

1. **Read the units first.** Lakhs versus crores has ended more attempts than any concept gap.
2. **Percentage change denominator is always the old value.**
3. **Cross-multiply to compare ratios** rather than dividing.
4. **Set selection is a scoring skill** — abandon calculation-heavy sets.
5. In data sufficiency, evaluate each statement **independently first**.
