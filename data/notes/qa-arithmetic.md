# Arithmetic — Percentage, Ratio, Profit, Interest, Time and Work

> This note is your formula sheet. Revise it weekly; the exam rewards recall speed, not derivation.

## Percentage

- **Fraction-percentage table (memorise, it saves minutes):**
  1/2 = 50% · 1/3 = 33.33% · 1/4 = 25% · 1/5 = 20% · 1/6 = 16.67% · 1/7 = 14.28% · 1/8 = 12.5% · 1/9 = 11.11% · 1/11 = 9.09% · 1/12 = 8.33% · 1/16 = 6.25% · 1/20 = 5%
- **Successive changes of a% and b%:** net = **a + b + ab/100** (use signs).
- If a value increases by x%, to bring it back the decrease needed is **[x/(100+x)] × 100**.
- **If A is x% more than B, then B is [x/(100+x)]×100 % less than A.**

## Ratio and proportion

- a : b = c : d ⇒ **ad = bc**. Componendo-dividendo: (a+b)/(a−b) = (c+d)/(c−d).
- If a : b = 2 : 3 and b : c = 4 : 5, then a : b : c = **8 : 12 : 15** (multiply to match b).
- **Partnership:** profit share ∝ (capital × time).

## Averages

- Average = sum / count. **Weighted average = Σ(wᵢxᵢ)/Σwᵢ.**
- **Alligation:** (Cheaper quantity)/(Dearer quantity) = (Dearer price − Mean)/(Mean − Cheaper price). Use it for mixtures, average speeds and blended interest rates — it is the fastest tool in the section.
- Average of the first n naturals = **(n+1)/2**.

## Profit and loss

- Profit% = (SP − CP)/CP × 100. **Always on cost price** unless stated otherwise.
- **SP = CP × (100 + profit%)/100.**
- Successive discounts of a% and b%: net discount = **a + b − ab/100**.
- If an article is sold at two prices with equal profit% and loss%, there is always a **net loss of (x²/100)%**.
- **Marked price, discount, cost price** chains: work backwards from SP.

## Simple and compound interest

```
SI  = P × R × T / 100
CI  = P[(1 + R/100)^T − 1]
Amount (CI) = P(1 + R/100)^T
Half-yearly: rate R/2, time 2T.   Quarterly: rate R/4, time 4T.
```

- **Difference between CI and SI for 2 years = P(R/100)²**
- For 3 years: **P(R/100)²(3 + R/100)**
- **Rule of 72:** money doubles in approximately 72/R years at compound interest.
- SI doubles a sum in 100/R years.

## Time, speed and distance

- Speed = distance / time. **1 km/h = 5/18 m/s**; 1 m/s = 18/5 km/h.
- **Average speed for equal distances at speeds x and y = 2xy/(x+y)** (harmonic mean). For equal *times*, it is the arithmetic mean.
- **Relative speed:** opposite directions → add; same direction → subtract.
- **Trains:** a train crossing a pole covers its own length; crossing a platform covers length + platform.
- **Boats:** downstream = b + s; upstream = b − s; **b = (down + up)/2**, **s = (down − up)/2**.

## Time and work

- If A does a job in n days, A's one-day work = **1/n**.
- A and B together: **1/a + 1/b**; combined time = **ab/(a+b)**.
- **Efficiency is inversely proportional to time.** If A is twice as efficient as B, A takes half the time.
- **Pipes and cisterns:** inlet positive, outlet negative; same arithmetic as work.
- **M₁D₁H₁/W₁ = M₂D₂H₂/W₂** — the universal work-equivalence formula.

## Exam pointers

1. **Successive percentage change: a + b + ab/100.** Signs matter.
2. **CI − SI for 2 years = P(R/100)².**
3. **Average speed for equal distances = 2xy/(x+y)** — never the plain average.
4. **Alligation** is the fastest route for every mixture-type question.
5. Equal profit% and loss% on two sales always gives a **net loss of x²/100 %**.
